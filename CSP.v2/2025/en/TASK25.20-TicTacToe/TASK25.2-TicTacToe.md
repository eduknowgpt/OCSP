# TASK25.2 – Tic-Tac-Toe Implementation

> Creator: Prof. Dr. Eduardo Cambruzzi, IFBA – Valença Campus

## 1. Problem

In the **Programming Logic** course of the **Integrated Technical Program in Informatics (1st year, IFBA – Valença Campus)**, students were challenged to apply basic structured programming concepts to design and implement the tic-tac-toe game (3x3), working in groups, with an individual oral defense afterward.

The game must allow **two human players** to alternate their moves, using the symbols “X” and “O”, until one of them wins (rows, columns, or diagonals) or the game ends in a draw.

The program must be robust: it must not accept invalid moves, must report the current state of the board, and must clearly indicate when the game is over.

## 2. Process

To develop the solution, students will have at their disposal:

* A programming environment (Python or another language defined by the instructor).
* A computer lab with workstations.
* Expository theoretical classes with examples of lists, matrices/arrays, conditionals, loops, and functions.

The solution must be developed in groups (2–3 students). However, assessment will be oral and individual. Each student must explain in detail:

* How the code is organized (functions, loops, conditionals, data structures).
* How the game flow unfolds step by step.

### Evidence Collected

* Delivered source code (file or repository).
* Practical demonstration of the program running.
* Individual oral explanation (recording, checklist, or instructor’s rubric).

### Assessment Criteria

1. **Technical Criterion**

   * Program compiles/runs without errors.
   * Proper handling of moves (validations, game rules).

2. **Cognitive Criterion**

   * Correctly explains the role of each function.
   * Justifies the use of lists/matrices, loops, and conditionals.
   * Can trace the execution flow (from the beginning to the end of a match).

3. **Attitudinal Criterion**

   * Effective participation in the group (not a mere spectator).
   * Respect for peers and fair division of tasks.
   * Collaborative attitude during the presentation.
