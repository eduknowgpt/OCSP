# CSP Phase 1 (A & B) Template Report

## 1. Introduction

This document serves as a template for reporting on **Phases 1A and 1B** of the **Competency Specification Process (CSP)**. These phases establish the pedagogical and contextual foundations before detailed competency modeling:

* **Phase 1A – Instructional Entity Analysis**
  Analyzes the structural and pedagogical components of an instructional entity (e.g., a PBL scenario, case study, simulation, or project). This phase clarifies its title, description, learner roles, solution process, learning context, expected products, and proficiency expectations—laying the groundwork for precise competency identification.

* **Phase 1B – Initial Competency Mapping**
  Builds on that foundation by extracting key knowledge elements, learning objectives, and skills implicit in the task. Using this analysis, the author establishes preliminary competencies—detailing their knowledge base, behavioral dispositions, and performance expectations—structured to align with educational context and outcomes.

By integrating these phases, this template ensures a coherent progression from understanding **“What is being taught and why?”** to specifying **“What learners should be able to do and demonstrate.”** This alignment fosters clarity, consistency, and traceability, supporting effective competency-based education in any instructional format.



## 2. Objective

This report illustrates how the CSP is applied to a specific instructional entity by:

- Enumerating required knowledge components.

- Identifying explicit and implicit learning objectives.

- Specifying the knowledge/skills pairs needed for effective task performance.

- Documenting relevant behavioral dispositions that support meaningful learning.



## 3. Report Structure

All CSP Phase1 Report share the same structure:

### **3. 1. Instructional Entity Analysis**  
- Purpose: Provide a comprehensive overview of the instructional entity.

- Include: The task’s nature, goals, expected outcomes, learner roles, and deliverables.

- How: Use the Instructional Entity Analysis Report template to guide your description and ensure consistency across reports.

      This phase lays the groundwork for identifying relevant knowledge, skills, and dispositions in the following sections.

### **3.2. Knowledge Enumeration**  
   Identifies the theoretical and practical knowledge needed, referencing taxonomies like ACM BoK CS2013, CS2023 or domain-relevant standards.

### **3.3. Learning Objectives Identification**  
   Extract and articulate the learning objectives implied in the instructional task..


### **3.4. Competency Definition**

   Define the essential competencies learners should develop, using the following standardized structure:

#### 🔹 Title & Description

- Provide a clear, focused title and a concise description that outlines the purpose, context, and expected outcome of the competency.

#### 🔹 Acquisition Context

- Describe the instructional or application scenario where the competency is developed or assessed (e.g., lab exercise, project scenario, simulation).

#### 🔹 Proficiency Scale

- Specify performance levels mapped to competency expectations.

#### 🔹 Knowledge Components

- List the essential theoretical and practical concepts learners must know to perform the competency effectively. Ensure these align with recognized frameworks (e.g., ACM CCS, domain taxonomies).

#### 🔹 Behavioral Dispositions

- Identify dispositions based on CC2020 Dispositions.

#### 🔹 Knowledge–Skill Mapping

- Link knowledge elements to cognitive actions using Bloom’s Revised Taxonomy:

   * **Cognitive Levels**: e.g., *Apply*, *Analyze*, *Create*
   * **Action Verbs**: chosen to reflect observable behaviors and appropriate cognitive levels.

### **3.5. Summary Table**

   A concise matrix summarizing title, knowledge, skills, and dispositions.


## 4. Conclusion
This report illustrates how Phases 1A and 1B of the CSP collaboratively establish a robust foundation for competency-based education. By first unpacking the instructional entity’s pedagogical and contextual design and then mapping its essential knowledge, skills, and dispositions, we ensure that each competency is:

- Anchored in authentic learning tasks

- Explicitly tied to theoretical and practical knowledge

- Measurable through clear performance expectations

- Geared toward meaningful learner outcomes

Moving forward, these well-defined competencies provide a solid basis for Phase 2 (Expert Review). The next step is to validate, refine, and finalize these competencies to ensure they are precise, relevant, and ready for instructional implementation and assessment.
