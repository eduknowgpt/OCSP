# Theory of Computation catalog

This directory contains reusable competence descriptions and available lifecycle narratives associated with Cycles 1–3. It is not the introductory-programming CM catalog: consult the [Cycle 4 registry](../CSP/cycles/cycle-04/CSP-Competency-Registry.csv) for that collection.

## Reading the entries

- `Cnn.md` and `Cnn.xx.md` describe a specification, including its source references and constituents.
- `Cnn_LifeCycle.md`, where present, documents selected events and relationships. Absence of that file does not establish absence of history.
- Task-specific roles, modes, and conditions belong to associations, not automatically to the reference definition.
- Follow the [RF-01-03 report](../CSP/cycles/CSP-Post-Cycle-Refinement-Report.md) and the relevant cycle dictionary when reconciling repeated descriptions.

Source links in the entries use the current task directories. References to the RF-01-03 preservation archive point to its identified version in Git history, since that archive is no longer part of the current checkout. Path maintenance does not rewrite the catalog definitions or lifecycle evidence. Use the [cycle task indexes](../CSP/cycles/README.md) to examine each package.
