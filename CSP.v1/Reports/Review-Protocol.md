# Competency Specification Review Protocol


## 1. Introduction

This **Competency Specification Review Protocol** serves as a formal instrument for **Phase 2 – Expert Review** within the **Competency Specification Process (CSP)**. Its primary objective is to guide structured, rigorous evaluation of competency specifications drafted in Phase 1, ensuring they meet established standards of:

* **Accuracy**: Validates that competency statements faithfully reflect domain knowledge and theoretical foundations.
* **Clarity**: Checks that each competency is articulated clearly, unambiguously, and with measurable precision.
* **Alignment**: Confirms that competencies are logically and meaningfully linked to learning objectives, domain knowledge, and required skills.

To facilitate this, the protocol utilizes **guided interviews** with subject-matter experts. These interviews are structured around core dimensions, ensuring comprehensive examination:

### Key Evaluation Dimensions

* **Knowledge Granularity**
  *Is the level of detail sufficient to capture necessary concepts without unnecessary complexity?*

* **Controlled Vocabulary**
  *Are terminologies and phrasing consistent, professional, and domain-appropriate?*

* **Bloom’s Taxonomy Verbs**
  *Do the selected action verbs align with intended cognitive levels and learning outcomes?*

* **Textual Clarity**
  *Are competency titles and descriptions free from ambiguity and well-constructed for instructional use?*

* **Knowledge Relevance**
  *Is each knowledge component appropriately mapped and essential to the task and its learning goals?*

### Impact of the Review

Expert feedback gathered through this protocol led to significant refinements, including:

* Reorganizing or refining knowledge categories for improved scope and coherence
* Standardizing terminology to enhance consistency across competencies
* Restructuring competency statements to strengthen instructional alignment
* Enhancing precision and clarity in wording to support assessment and implementation

This protocol ensures an iterative, transparent, and pedagogically anchored review process that enhances the validity, usability, and educational impact of competency specifications for PBL tasks.




# 2. Scope of Use

* Who: Expert reviewers (subject-matter experts, competency designers, instructional designers)

* When: Implemented during Phase 2, immediately following initial competency drafting (Phase 1)

* Why: To confirm that competencies are accurate, clear, aligned, and contextually grounded, and to produce validated specifications ready for semantic structuring in Phase 3.

## 3. Instructional Entity Description Analysis

**Objective:** Verify that the instructional entity foundation sufficiently supports the competency definitions.

| **Aspect**               | **Rating Options**              | **Evaluator Notes**                                                      |
| ------------------------ | ------------------------------- | ------------------------------------------------------------------------ |
| **Task Title**           | Clear / Needs Revision      | Does the title accurately reflect the task’s focus and scope?            |
| **Problem Description**  | Clear / Needs Clarification | Is the problem statement explicit, complete, and contextually relevant?  |
| **Solution Development** |  Appropriate /  Incomplete    | Are solution steps actionable and aligned with defined competencies?     |
| **Expected Outcomes**    |  Well Specified /  Misaligned | Do outcomes clearly relate to the tasks and competencies being assessed? |

> **Tip:** Note how each task element supports or limits the competencies (e.g., vague descriptions may hide essential required knowledge/skills).



## 4. Review of Enumerated Knowledge

**Objective:** Confirm that knowledge components are comprehensive, relevant, and properly scoped.

| **Criterion**         | **Yes / Maybe / No** | **Evaluator Notes**                                                        |
| --------------------- | -------------------- | -------------------------------------------------------------------------- |
| **Comprehensiveness** |                      | Are all essential knowledge areas present?                                  |
| **Relevance**         |                      | Does each knowledge element directly support task or competency goals?     |
| **Appropriateness**   |                      | Is the level of detail correctly balanced—not too general or too granular? |

> **Tip:** Check alignment with recognized taxonomies, such as ACM CCS.







## 5. Review of Learning Objectives (LOs)

**Objective:** Ensure that the learning objectives are explicit, aligned, and pedagogically sound.

| **Criterion**       | **Yes / Maybe / No** | **Evaluator Notes**                                                         |
| ------------------- | -------------------- | --------------------------------------------------------------------------- |
| **Completeness**    |                      | Do the LOs cover both explicit and implicit learning goals?           |
| **Relevance**       |                      | Are all LOs essential within the context of the task?               |

> **Tip:** Use Bloom’s verbs to check alignment with intended cognitive levels.







## 6. Review of Competency Definitions

### 6.1 Competency Title & Description

| **Subcomponent**           | **Yes / Maybe / No** | **Evaluator Notes**                                        |
| -------------------------- | -------------------- | ---------------------------------------------------------- |
| **Title Clarity**          |                      | Is it concise, descriptive, and focused?                   |
| **Description Precision**  |                      | Is the phrasing clear, measurable, and free of ambiguity?  |
| **Contextual Application** |                      | Is the competency tied explicitly to the task scenario?     |
| **Scope Coverage**         |                      | Does it include all necessary elements without redundancy? |



### 6.2 Knowledge Evaluation

**Objective:** Ensure that each competency’s knowledge components are robust, accurate, and contextually relevant.

| **Criterion**            | **Yes / Maybe / No** | **Evaluator Notes**                                                             |
| ------------------------ | -------------------- | ------------------------------------------------------------------------------- |
| **Theoretical Validity** |                      | Does it accurately reflect essential domain theory or professional knowledge?   |
| **Comprehensiveness**    |                      | Are all relevant knowledge areas included for effective competency performance? |
| **Relevance**            |                      | Is each knowledge element essential and appropriately mapped to the competency? |
| **Granularity & Scope**  |                      | Is the content scoped correctly—not too broad nor overly detailed?              |

> **Tip:** Compare knowledge items against recognized taxonomies (e.g., ACM CCS) to verify appropriate depth and coverage.


### 6.3 Disposition Evaluation

**Objective:** Verify that each competency includes pertinent dispositions—professional attitudes or mindsets—supporting effective performance.

| **Criterion**                   | **Yes / Maybe / No** | **Evaluator Notes**                                                                  |
| ------------------------------- | -------------------- | ------------------------------------------------------------------------------------ |
| **Behavioral Alignment**        |                      | Does the disposition align logically with the competency’s performance requirements? |
| **Explicit Articulation**       |                      | Is the disposition specified clearly, rather than implied?                           |
| **Relevance & Appropriateness** |                      | Is it a meaningful “habit of mind” that enhances competency in real-world contexts?  |

> **Tip:** Dispositions—such as persistence, collaboration, adaptability—serve as the “glue” that integrates knowledge and skills for effective on-the-job performance.




## 6.4 Knowledge–Skill Pairing & Bloom Alignment

**Objective:** Verify that each knowledge–skill pairing is logically justified and aligned with the correct cognitive level per Bloom’s Revised Taxonomy.

| **Criterion**               | **Yes / Maybe / No** | **Evaluator Notes**                                                                                                                                                                |
| --------------------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Bloom-Level Suitability** |                      | Does the described action (skill) align with an appropriate Bloom’s level?  |
| **Verb Effectiveness**      |                      | Are verbs specific and action-oriented (e.g., “construct,” “analyze,” “evaluate”)                   |
| **Pairing Justification**   |                      | Is it clear how the knowledge element supports the skill?                          |

> **Tip:** Conduct a task breakdown (e.g., “insert coin → validate → dispense”) and ensure each step is captured by a competency that pairs relevant knowledge and skill at the correct cognitive level.
