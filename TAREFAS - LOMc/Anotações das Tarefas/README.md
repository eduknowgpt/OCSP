# Annotations and working records

Task annotation, interview analysis, process guidance, and re-specification documents are grouped here. Subdirectories preserve different purposes and documentary states. They are not a single chronological sequence.

Some files contain working instructions and draft explanations. The directory named Tarefa PBL_Original also contains interventions; do not treat its contents as untouched source statements.
