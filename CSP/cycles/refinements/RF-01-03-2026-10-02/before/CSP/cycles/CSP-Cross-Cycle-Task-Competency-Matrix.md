# CSP Task–Competency Relations Across Cycles 1–3

## Scope and reading guide

This matrix covers 14 tasks: five in Cycle 1 (2021), four in Cycle 2 (2022), and the five consolidated Theory of Computation tasks in Cycle 3 (2025). It uses the current retained associations in the cycle mappings, checked against the task packages. Earlier associations and source-definition differences are retained separately.

For origins, reasons, component comparisons and corrective recommendations, see the [competency lifecycle](CSP-Cross-Cycle-Competency-Lifecycle.md).

An association is a documented task–competency link. It does not establish that the competency was independently assessed or mastered. Conditional and optional associations remain in the totals. Specialization and composition links do not create additional task rows.
