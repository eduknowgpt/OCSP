# Course Plan: Algorithms and Programming Logic

**Federal Institute of Education, Science and Technology of Bahia (IFBA)**  
**Valença Campus - Academic Department**  
**Academic year: 2026**

| Field | Details |
|---|---|
| Course | Algorithms and Programming Logic |
| Year level | 1st year |


## Course Description

Compilers and interpreters. Concepts of algorithms, data, variables, and instructions. Basic data types and structures. Operators. Conditional and repetition statements. Composite data structures: arrays and matrices. Subprograms: functions, procedures, and recursion. Algorithms and applications.

## Objectives

- Interpret computational logic and understand its importance in software programming.
- Interpret and develop pseudocode, flowcharts, and algorithms.
- Understand the basic constructs of structured programming through practical use of a structured programming language.
- Perform desk checks and software debugging.

## Expected Outcomes

- Develop skills such as problem solving, teamwork, leadership, creativity, interpretation, and analysis, among others.
- Identify the main ways of representing algorithms.
- Develop algorithms using the structured programming paradigm.
- Identify and correct logical or syntax errors in software.

## Course Content

### 1. Programming Logic

- Concept of logic.
- Concept of programming logic.
- Concept of programming languages.
- Interpreted and compiled languages.
- Types of programming languages.
- Uses of programming languages.
- Data processing.

### 2. Algorithms

- Concept.
- Importance.
- Properties.
- Construction.
- Forms of representation.

### 3. Introduction to a Structured Programming Language

- Introduction.
- History.
- Notation used.
- Compiler or interpreter.
- Language syntax.

### 4. Fundamentals

- Data types: constants and variables.
- Expressions: arithmetic and literal expressions.
- Comments.
- Assignment statements.
- Input and output statements.

### 5. Decision Structures

- Relational and logical operators.
- Simple conditional statements.
- Compound conditional statements.
- Selection statements.

### 6. Repetition Structures

- Loops with a condition tested at the beginning.
- Loops with a condition tested at the end.
- Loops with a control variable.

### 7. Basic Data Structures

- One-dimensional arrays.
- Matrices.

### 8. Modularization

- Functions.
- Functions with parameter passing.

### 9. Software Testing

## Teaching Methods

The course will use the following teaching strategies:

- Lectures.
- Practical laboratory classes.
- Interactive exercises and playful learning activities.
- Classroom discussions.

## Teaching Resources

The following resources and media will be used:

- Multimedia projector.
- Whiteboard.
- Computer.
- Computer laboratory.
- Library.

## Assessment Instruments

- Individual performance assessments through written and practical activities.
- Student coursework, including:
  - Research and library activities.
  - Development of solutions to problem situations.
  - Group activities.
  - Software development projects.
  - Completion of exercise sets.
  - Participation in discussions.

## Learning Recovery and Reassessment

Students whose achievement is below 60% of the combined score for assessment activities will be entitled to a learning recovery opportunity. This will take place at the end of each instructional unit, seven days after feedback on the final assessment has been provided.

The recovery assessment will cover content addressed during the teaching and learning process and will be graded on a scale from zero to ten points. The higher result will prevail when comparing the combined regular assessment score with the recovery assessment score.

In addition, in accordance with CONSEPE/IFBA Resolution No. 41 of August 18, 2022, which approves IFBA's Academic Regulations for Upper Secondary Technical Vocational Education, content review will be provided during student consultation hours.
