Read each cycle's data dictionary before aggregating rows. Distinct identities, current task associations, historical rows, and composition memberships are different units. The cycle is an application grouping, not automatically a complete process version. Post-cycle maintenance must remain distinguishable from decisions documented during an application.

For a specific claim, follow the source locator to the report and applicable state. A registry row or a matrix entry does not independently establish the semantic adequacy of the relationship.
