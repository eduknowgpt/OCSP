# CSP documentation and application materials

This directory connects the reference process, reporting instruments, and four documented application cycles. Start with the instruments to prepare a new specification or with a cycle README to inspect an existing application.

| Location | What to find |
| --- | --- |
| [reports](reports/README.md) | Instructional analysis, specification, review, and semantic consolidation guides. |
| [cycles](cycles/README.md) | Cycle scopes, task-package indexes, registries, mappings, and cross-cycle accounts. |
| [Theory of Computation catalog](../Cat%C3%A1logo/README.md) | Reusable definitions and available lifecycle narratives. |
| `images/` | Logo used by repository documentation. |
| `registry/` | Empty in this snapshot; the maintained CSV registries are inside each cycle. |

The four reporting activities are Phase 1A (instructional analysis), Phase 1B (specification and contextual association), Phase 2 (review and documented adjustment), and Phase 3 (semantic consolidation and maintenance). The current reference organization does not imply that every historical application produced every instrument separately.

Cycle data describe specifications and intended task associations. They must not be interpreted as learner attainment records. See the [repository overview](../README.md) for the contribution, scope, related publications, and relationship with OntoKSD.
