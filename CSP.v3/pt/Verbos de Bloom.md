# Verbos Taxonômicos de Bloom

| Nível | Verbos |
|---|---|
| Lembrar | identificar, listar, localizar, nomear, reconhecer, recordar |
| Compreender | descrever, explicar, interpretar, relacionar, resumir, traduzir |
| Aplicar | aplicar, demonstrar, executar, implementar, resolver, usar |
| Analisar | analisar, categorizar, comparar, contrastar, diferenciar, investigar |
| Avaliar | avaliar, criticar, julgar, justificar, selecionar, validar |
| Criar | construir, criar, elaborar, formular, planejar, propor |
